## Release blockers / mandatory qualification

1. **Workstation onboarding:** `cmd/baha/onboarding_bundle.go` currently implements `onboardingEnrollmentBaseURL() string { return "" }`. This prevents a credible finished native one-use enrollment claim until replaced and tested. PR #1521 was open at inspection time. Inspect latest PR head before final qualification.
2. **Ecosystem compatibility:** existing Console and Connector `integration-candidate.json` point to 0.4.26; only advance them after one proven immutable source matrix, then validate real browser/auth and Connector mTLS/remote lifecycle.
3. **Demo source pin:** final 0.4.27 demo commit must pass the acceptance path and be recorded in the required `.demo-ref` file before release workflow.
4. **Documentation QA:** run MkDocs EN/DE strict builds, link/reference checks, versioned CLI command index generation/consistency check and verify actual command output from release candidate.
5. **Core tests:** PR CI, native local Docker/rootless Podman, remote CLI -> Core path, auth/ownership, backup/recovery, upgrade, fresh installation and uninstall safety.
6. **Release workflow:** check pre-release and release jobs for selected green tests and successful packaging; inspect checks on the actual frozen commit. Verify artifact versions and checksums/signatures where produced.
7. **User-facing migration:** determine changes from v0.4.26 and accurately document any required migration, compatibility limitation or breaking change before publication.
8. **Final publish:** only with owner authorization: merge reviewed release changes, freeze `main`, tag, publish release assets, verify downloads and docs site after deployment. No earlier task or draft constitutes authorization.

## Writing rules

Public notes describe only user-relevant improvements and supported behavior; avoid technical issue IDs, CI trivia and unverified benchmark claims. Keep operational QA here, not in public-facing release notes. Public draft text can read as complete release copy, but acceptance must still be verified before publication.
