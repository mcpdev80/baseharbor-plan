# v0.7.x · Kubernetes runtime

Source: [baseharbor#430](https://github.com/mcpdev80/baseharbor/issues/430). Tasks: [views/releases/v0.7.x.md](../views/releases/v0.7.x.md). Master roadmap: [ROADMAP.md](../ROADMAP.md).

Parent of the v0.7.x Kubernetes Runtime implementation line. **Namespace-only operation remains the primary authorization profile.** Children cover the namespace-scoped runtime foundation (core-102, v0.7.0; implementation and evidence outstanding — historical runtime-selection seams are not runtime support), security/networking, exposure, storage, stateful workloads, availability, conformance, portability proof (core-304…core-310) and delegated delivery/GitOps (core-325, v0.7.8). Historical v0.4 foundations stay delivered.

Depends on the v0.5 contract freeze and its compatibility acceptance. v0.6.x is reserved for additional compatible availability extensions only (the original HA foundation was delivered before the freeze) and is not an unconditional prerequisite. Each patch release applies the [standard pre-release gate](v0.5.x.md#standard-pre-release-gate).
