## Review

The central selector is reached from `List`, covering the list wrappers, and ordinary `dev` / `prod`
cases are covered. The resolver is still unsafe for valid environments containing hyphens and for
legacy application-scoped records without the newly persisted environment field. `validateSlug`
permits `prod-west`, while `environmentFromProjectName` uses only the final hyphen token; that
record is classified as `west`, so a `west` caller can see it. For reserved tokens such as
`prometheus` and `loki`, the resolver returns empty and `SourceMatchesEnvironment` treats the
unknown application-scoped source as environment-agnostic. Existing persisted records can remain
in this state until re-registration.

**CODEX-REVIEW: REQUEST CHANGES.** This cross-environment visibility leak blocks acceptance.

Recipe: require an explicit or unambiguous environment for application-scoped sources; do not
interpret an unresolved application-scoped record as environment-agnostic. Preserve the current
shared/environment-neutral behavior. Add exact regressions for `prod-west` versus `west`, a
reserved environment token, and an application-scoped legacy record without a resolvable
environment. Run the exact-head required CI after correction.
