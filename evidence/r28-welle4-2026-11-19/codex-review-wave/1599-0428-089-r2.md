- `TestPersesComposeAliasLivesOnGatewayNotPerses` (`:112-160`) asserts that the backend alias is on the gateway network (`:123-130`), the Perses service has no own `networks` while joining the gateway namespace (`:131-134`), and the Perses command binds loopback rather than `0.0.0.0` (`:135-149`). It checks the gateway route uses that alias (`:150-159`).

## B2 — Perses authentication provider schema

`internal/serviceaccess/perses_config_render.go:76-96` renders `security.enable_auth: true` and `security.authentication.providers.enable_native: true` under the `security` block. `TestPersesRenderedConfigAuthenticationProviderIsValid` (`internal/application/perses_fix7_regression_test.go:188-235`) parses the produced YAML, requires both values, requires the encryption-key file reference, and rejects a document-level `authentication` key.

I checked the pinned upstream v0.55.0 model: `Config` owns `Security`; `Security` owns `Authentication`; `AuthenticationConfig` owns `Providers`; `AuthenticationProviders` has the `enable_native` field. `Security.Verify()` rejects `enable_auth` when no provider is enabled. The corrected nesting is consumed by the schema; the rejected top-level key is not the provider location. [Perses v0.55.0 config model](https://github.com/perses/perses/blob/v0.55.0/pkg/model/api/config/config.go), [security model and verification](https://github.com/perses/perses/blob/v0.55.0/pkg/model/api/config/security.go), [authentication provider model](https://github.com/perses/perses/blob/v0.55.0/pkg/model/api/config/authentication.go).

The earlier encryption-key projection concern is also corrected in this candidate: `internal/application/perses_runtime.go:274-340` generates 32 random bytes, persists the authoritative file owner-only, and projects a container-readable copy; `internal/serviceaccess/perses_compose_realization.go:410-446` fails closed if the projection is absent and mounts the config/key paths read-only. The regression suite checks missing-key failure and the 0600/0644 modes. This matches the upstream requirement for a 32-byte key file.
