## Finding and verdict

**REQUEST CHANGES.** The lifecycle convergence gate is inverted, so machine transports skip runtime reconciliation while direct CLI invocations execute it immediately—the opposite of the documented contract.

In `cmd/baha/perses_lifecycle.go`, `persesMachineConvergeDeferred` is documented as true when convergence should be deferred for direct human CLI use and false for MCP/HTTP, which must converge immediately. Its implementation returns `cliInvocationTransport(ctx) != "cli"`, making it true for machine transports. `executePersesLifecycle` then calls apply only when `!persesMachineConvergeDeferred(ctx)` (lines 154–157). Thus MCP/HTTP skip apply; direct CLI runs apply. `main.go` tags direct CLI invocations as `"cli"`.

This contradicts the command/tool descriptions that machine transports converge immediately and the human CLI defers convergence to `baha app apply`. It affects enable, disable, and remove whenever the manifest changes.

## Recipe

- **Files:** `cmd/baha/perses_lifecycle.go`; `cmd/baha/perses_lifecycle_test.go` and the shared CLI/MCP lifecycle tests.
- **Change:** Align the predicate name/meaning and the apply condition so machine transports execute the shared apply lifecycle while direct human CLI defers it. Emit the deferred-apply notice for every changed direct-CLI mutation (including disable/remove), or revise the documented contract with an explicit owner decision. Preserve no-op behavior.
- **Tests:** Add a transport/action matrix for enable, disable, and remove: direct CLI changes the manifest without invoking apply and reports the deferred action; MCP stdio and HTTP/remote changes invoke apply; unchanged selections do not invoke apply. Assert manifest/backend ownership invariants and CLI JSON/MCP structured-result parity. Run focused lifecycle and MCP tests, then require fresh terminal exact-head CI with `PR Selected Checks` and all affected Go-unit cells green.
- **Stop:** Stop if any machine transport can report success after changing the manifest without running apply, or if direct CLI both defers convergence and omits the required actionable notice. Keep the card in `review`; no merge in this wave.
