## Root-cause note
The round-3 EREIGNIS barrier compared entry.Info() mtime against the walk-start
baseline. entry.Info() returns the SAME mtime the walk already captured on entry
(proven: two sequential Stat()/Info() calls on one path are equal), so the
per-file comparison was always equal and the barrier never fired — the snapshot
flake. Round-4 re-stats each path with a fresh os.Lstat mid-walk, so the barrier
now fires on a real divergence and the deterministic witness passes reliably
(-race -count=50 green across many runs; hosted 42083071514 success).
