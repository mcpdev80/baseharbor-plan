## RECIPE

- **Files:** `internal/application/telemetry_authorization.go`; keep the narrowly scoped `cmd/baha/app_workload.go` fix and its W154 regression coverage.
- **Change:** Remove the unconditional non-OTLP `os.ErrNotExist` → empty-map fallback from `readWorkloadRuntimeEnv`. The specified state is handled by the runtime-directory ownership check in `stopRepositoryWorkload`; do not suppress missing runtime bindings in shared workload readers. If a distinct valid state with an existing runtime directory but absent `runtime.env` must be supported, isolate that behavior to the destroy/retirement call path and document its ownership proof rather than changing shared readers.
- **Test requirement:** On the agreed develop baseline, run the W154 test(s) and preserve the literal missing-`runtime.env` failure; on the corrected candidate require rc=0, no running workload and no remaining project ownership. Keep W138 never-delivered tests and normal apply/destroy lifecycle regressions green. Add a focused regression for any separately supported existing-directory/missing-env state and verify other workload readers still fail closed when required bindings are absent. Run the required paired package checks in the supported database/Docker environment and retain terminal hosted checks for the final SHA.
- **Stop criterion:** Keep REJECT until the telemetry-file scope is removed or a separate call path and regression prove that the shared missing-env fallback is required and safe; stop the correction if a valid destroy case still fails, ownership/runtime remains, the #1375 cell regresses, a missing required binding is silently accepted by another caller, or required checks are nonterminal/red/skipped when applicable.
