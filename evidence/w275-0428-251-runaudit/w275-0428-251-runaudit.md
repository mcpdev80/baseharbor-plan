## (3) Mechanism test — which is true? Each with witness

### (i) Workflow file must exist on the default branch for the event to be considered — TRUE HERE
- main copy of pr-config-matrix.yml: `branches: [develop]` at main:4-5.
- Commit that ADDED it to main: `d512653aa2e5e69e734caf9b64b5043f409ade42` "ci(demo): route fixture gates on pull requests" author_date=2026-11-26T00:06:55Z.
- Parent `d512653a^` (before landing): `git show d512653a^:.github/workflows/pr-config-matrix.yml` → `fatal: path '.github/workflows/pr-config-matrix.yml' exists on disk, but not in 'd512653a^'` = ABSENT on main before this commit.
- Timeline: file lands on main 00:06:55Z  →  #170 events 00:09:09/10Z  →  **file arrived AFTER the PR fired.** Classic new-workflow-on-feature-branch case: a pull_request's workflow set is computed from the default branch at event time; the file was not there, so no run.
- Control confirms (i): pr-guided-consent.yml exists on main (identical blob) and DID produce a pull_request run.

### (ii) paths evaluated against the PR diff at event time — NOT the cause here
- #170 changed files (base...head diff): `modified tests/config-matrix/run.sh +11/-12` — the ONLY changed file.
- main copy paths list includes `tests/config-matrix/**` (main:13) → run.sh WOULD match. develop copy also includes `tests/config-matrix/**` (develop:14). So the paths filter WOULD have selected a run. The file was not filtered out — it was simply never in the workflow set because of (i).
- #179 (cda6aa70, base=develop, head=w198-1842-demo-fixture-fix-forward) changed `tests/reconciliation/run.sh` which IS in main paths (main:18) → paths not the blocker; its 0 check-runs trace to (i)/(iii) timing or that the run fired before/after this audit snapshot.

### (iii) New workflow on develop does not run until it is also on main — THE cause
- develop added the workflow at `6d06eab0ed0cd890ab9f818100ff84698e0347f5` "ci(demo): add pr-config-matrix workflow for 0428-250 exact-head acceptance" author_date=2026-11-25T17:39:05Z.
- `6d06eab0 IS ancestor of b086cf58` (#170 head) → the file existed on develop when #170's head was cut. So on develop it was present.
- But default-branch resolution needs it on main, which happened only at 00:06:55Z (d512653a) — 57 min after #170's events. Hence zero runs. This is mechanism (iii) + (i) jointly, and it is the sole operative cause.
