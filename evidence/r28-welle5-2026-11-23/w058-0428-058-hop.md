## The defect (before)

```go
if decision, ok := operatorauth.AuthorizationDecisionFromContext(ctx); ok && decision.Allowed {
    // ...actor copy...
    event.AuthorizationResult = "allow"
} else if principal, ok := operatorauth.PrincipalFromContext(ctx); ok {
    // ...actor copy...
    event.AuthorizationResult = "allow"   // BUG: present denied decision fell through here
} else {
    event.AuthorizationResult = "deny"
}
```
A present decision with `Allowed=false` skipped the first branch, matched the principal branch, and wrote `allow` — corrupting the audit record even when a verified principal coexisted with a denial.

## The fix

`cmd/baha/secret_operations.go` `recordSecretAudit`:
```go
// A present AuthorizationDecision takes precedence over any principal: a
// verified principal can coexist with a policy denial (authorizeMCPOperation
// stores denied machine decisions in this context), so a present decision
// must never fall back to principal-allow. Only when no decision is present
// does the verified principal stand in.
if decision, ok := operatorauth.AuthorizationDecisionFromContext(ctx); ok {
    event.Actor.Subject = decision.Actor.Subject
    event.Actor.Assurance = decision.Actor.Assurance
    event.Actor.Methods = append([]string(nil), decision.Actor.Methods...)
    if decision.Allowed {
        event.AuthorizationResult = "allow"
    } else {
        event.AuthorizationResult = "deny"
    }
} else if principal, ok := operatorauth.PrincipalFromContext(ctx); ok {
    // ...actor copy...
    event.AuthorizationResult = "allow"
} else {
    event.AuthorizationResult = "deny"
}
```

`cmd/baha/env_destroy.go` `recordEnvDestroyAudit` — same contract, same fix:
```go
if decision, ok := operatorauth.AuthorizationDecisionFromContext(ctx); ok {
    // present decision takes precedence; deny never falls back to principal-allow
    if decision.Allowed {
        event.AuthorizationResult = "allow"
    } else {
        event.AuthorizationResult = "deny"
    }
} else if _, ok := operatorauth.PrincipalFromContext(ctx); ok {
    event.AuthorizationResult = "allow"
} else {
    event.AuthorizationResult = "deny"
}
```

`internal/operatorauth/context.go` — added exported test/caller helper mirroring `WithVerifiedPrincipal`:
```go
// WithAuthorizationDecision installs a stored AuthorizationDecision in the
// enforcement context.
func WithAuthorizationDecision(ctx context.Context, decision AuthorizationDecision) context.Context {
	ctx = WithEnforcement(ctx)
	setAuthorizationDecision(ctx, decision)
	return ctx
}
```

Regression test `cmd/baha/secret_audit_test.go` `TestRecordSecretAuditPresentDeniedDecisionOverridesVerifiedPrincipal`:
- Builds an enforcement context with a verified principal AND a present `AuthorizationDecision{Allowed:false, Operation:"secret.set"}`.
- Calls `recordSecretAudit`; asserts the stored event has `AuthorizationResult="deny"` and actor follows the denied decision (not the principal).
- Fixture sanity: `AuthorizationDecisionFromContext` returns `ok=false` before the decision is installed.
