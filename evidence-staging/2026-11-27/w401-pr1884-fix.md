## Correction block — finding → change

Finding (verbatim in the mission): process-global interactive consent can survive its invocation — mismatch path does not consume (app_candidate_consent_interactive.go:45-50), explicit --confirm-candidate wins without consuming (:72-76), and a successful lifecycle has no unconditional cleanup (only recordFailedDeployment cleared, app_apply.go:268-272).

- cmd/baha/app_candidate_consent_interactive.go:46-58 — takeInteractiveCandidateConsentDigest now retires the binding FIRST on every read: matching identity consumes exactly once (unchanged), identity MISMATCH also clears the saved binding (fail closed, never consumable later by the original identity).
- cmd/baha/app_candidate_consent_interactive.go:82-97 — candidateConsentForWrite: when an explicit --confirm-candidate value wins the resolution order, the pending interactive binding of this invocation is consumed AND unconditionally cleared, so a flag-run can never leave a live 'y' for a later invocation.
- cmd/baha/app_apply.go:139-146 — runApplicationApplyLifecycle: unconditional clear at lifecycle ENTRY plus `defer clearInteractiveCandidateConsentBinding()` at EXIT (success AND failure). This is the recipe's "unconditional cleanup at end of apply lifecycle"; recordFailedDeployment's clear stays (now redundant-fast, unchanged semantics).
- cmd/baha/app_apply.go:114-124 — executeApplicationApplyLifecycle: same entry+deferred exit pair so the EDIT/Results entry path gets exit coverage on every route too (idempotent with the inner run's clearing).
- cmd/baha/app_remote_lifecycle.go:83-90 — executeRemoteApplicationApply: entry+exit unconditional clearing, because the local lifecycle's remote early-return (app_apply.go) never reaches runApplicationApplyLifecycle's defer.
- Net semantics: every read path consumes; a stale binding cannot cross an invocation boundary even for the identical unchanged candidate; the current-source digest recomputation and constant-time comparison at the write boundary are untouched (stricter, never looser).
